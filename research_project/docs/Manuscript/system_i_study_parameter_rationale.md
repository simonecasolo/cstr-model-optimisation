# System I — rationale for the study parameters (decision log)

Started 2026-11-08, after the controller-form fix. One entry per parameter: the value used,
why, the evidence, and the **status** of the decision:

- **pre-set**: fixed before the result it governs was computed;
- **amended**: changed after seeing results (the reason and the original are recorded);
- **inherited**: carried over unchanged from earlier project work, not re-examined here
  (a candidate for a sensitivity check, not a validated choice);
- **user**: decided by the author in discussion; the rationale given is what the decision
  rested on.

Numbers quoted come from the named notebooks/results files in this repository.
Companion documents: `docs/Manuscript/system_i_rerun_plan.md` (what to run, in which order)
and `HANDOFF_2026-11-08_ws_convergence.md` (operational log).
